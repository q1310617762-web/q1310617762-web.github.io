这个博客是我自己动手搭的。写一篇记录，方便以后回看，也给想搭博客的朋友一份参考。

## 用到的技术

| 部分 | 选择 | 为什么 |
| --- | --- | --- |
| 框架 | Astro | 内容优先、输出纯静态、加载极快 |
| 样式 | Tailwind CSS | 原子化，改起来快 |
| 内容 | Markdown | 写文章只关注内容本身 |
| 部署 | 静态托管 | 免费、省心 |

## 搭的时候做了什么

1. **先定设计**：把颜色、圆角、间距做成统一的「设计令牌」，后面所有组件都引用它。
2. **再拆模块**：导航、卡片、文章列表、标签云、相册、播放器……一个个做，最后拼起来。
3. **最后调体验**：深色模式、代码高亮、站内搜索、返回顶部这些细节。

## 这个站点有的功能

- 文章列表 / 分页 / 分类 / 标签 / 归档
- 站内搜索（本地索引，不用后端）
- 相册（点击放大看大图）
- 音乐播放器
- 深色模式、RSS 订阅
